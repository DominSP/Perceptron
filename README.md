# Perceptron

## Overview

This project explores the Perceptron, one of the fundamental algorithms
underlying neural-network and machine-learning concepts.

## Project Focus

The Perceptron is a simple linear classifier that learns a decision
boundary from labeled training data.

## Topics

-   Perceptron algorithm
-   Machine learning
-   Linear classification
-   NumPy
-   Algorithm implementation

## Purpose

The project was created to understand the basic principles behind the
Perceptron and its learning process.

## Repository Structure

The repository contains the source files and materials used for the
Perceptron project.
